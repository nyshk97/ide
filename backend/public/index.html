AI コーディング CLI のための
All-in-One ワークスペース

Claude Code / Codex CLI などのターミナル系 AI ツールに最適化。
ターミナル・ファイルプレビュー・プロジェクト切替を 1 画面で。

特徴

特定の AI ツールやエディタに縛られず、CLI 中心で開発したい人のために。

libghostty ターミナル統合

Ghostty 設定 (~/.config/ghostty/config) をそのまま継承。プロジェクトごとにタブを保持。

VS Code 風ファイルツリー

SwiftUI 製のツリー + プレビュー (シンタックスハイライト)。閲覧専用に振り切って軽快に。

プロジェクト切替 (Ctrl+M)

MRU 順のプロジェクト切替オーバーレイ。ターミナル状態を保ったまま 1 アクションで移動。

Cmd+P / Cmd+Shift+F

ファイル名検索と全文検索が即座。プレビューはツリーに戻る Cmd+J で 1 タップ往復。

git diff プレビュー

Cmd+D で差分を全画面表示。レビューや作業中の確認に。

Apple Silicon ネイティブ

macOS 専用 / Apple Silicon 限定。Sparkle で自動アップデート対応。
