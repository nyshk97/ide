プライバシーポリシー

最終更新日: 2026-05-24

⚠️ 本ページはドラフトです。launch 前に確定版に差し替えます (Phase 8)。

1. 収集する情報

本ソフトウェアおよび関連サービス (以下「本サービス」) は、以下の情報を収集します。

  • 購入時の情報: 決済代行業者 (Stripe) を通じて、メールアドレスを受領します。クレジットカード情報は Stripe が直接処理し、当方は保持しません。
  • ライセンス検証時の情報: ライセンスキー、メールアドレス、デバイス識別子 (IOPlatformExpertDevice UUID の SHA256 ハッシュ)、デバイス名 (ComputerName)、OS バージョン、アプリバージョン、アクティベート日時、最終アクセス日時。
  • サポート時の情報: 利用者がサポートに連絡した際に提供されたメールアドレスおよびその他の情報。

2. 収集しない情報

  • 本ソフトウェアで操作したファイル名・ファイル内容・コマンド履歴・ターミナル出力
  • 位置情報
  • クラッシュレポート (v1.0 時点では非対応。将来 opt-in 形式での導入を検討する場合があります)

3. 利用目的

収集した情報は、以下の目的でのみ利用します。

  • ライセンスの発行・検証・管理
  • 不正利用 (ライセンスキーの第三者共有等) の防止
  • サポート対応
  • サービス終了時のユニバーサルトークン配布

4. 第三者提供

収集した情報は、以下の場合を除き第三者に提供しません。

  • 利用者の同意がある場合
  • 法令に基づく場合
  • 本サービス運用上必要な業務委託先 (決済: Stripe、メール送信: Resend、インフラ: Cloudflare) への提供

5. 利用する第三者サービス

  • Stripe: 決済処理。プライバシーポリシー
  • Resend: ライセンスキー送付メールの配信。プライバシーポリシー
  • Cloudflare: Web サイトおよび API のホスティング。プライバシーポリシー

6. 自動アップデート (Sparkle) の通信

本ソフトウェアは Sparkle フレームワークを用いた自動アップデート機能を備えており、利用者がアップデート確認操作を行ったときに当方サーバーに対してアプリバージョン情報を含む HTTP リクエストを送信します。IP アドレスはアクセスログに一定期間記録されますが、個人を特定する目的では使用しません。

7. 保管期間

ライセンス情報は、利用者がライセンスを保有する限り保管します。サポート対応に関する情報は対応完了から原則 1 年間保管します。

8. 利用者の権利

利用者は、自己の情報の開示・訂正・削除を support@polepole.dev 宛に請求できます。ライセンス情報の削除は本ソフトウェアの利用停止を伴います。

9. 変更

本プライバシーポリシーは予告なく変更される場合があります。変更後は本ページに掲載した時点から効力を生じます。

10. お問い合わせ

本プライバシーポリシーに関するお問い合わせは support@polepole.dev までお願いします。
