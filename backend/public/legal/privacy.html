プライバシーポリシー

最終更新日: 2026-05-24

1. 収集する情報

本ソフトウェアおよび関連サービス (以下「本サービス」) は、以下の情報を収集します。

  • 購入時の情報: 決済代行業者 (Stripe) を通じて、メールアドレス、購入金額・通貨、Stripe Checkout Session ID、Payment Intent ID、購入日時を受領・記録します。クレジットカード番号その他の決済情報そのものは Stripe が直接処理し、当方は保持しません。
  • ライセンス検証時の情報: ライセンスキー、メールアドレス、デバイス識別子 (IOPlatformExpertDevice UUID の SHA256 ハッシュ)、デバイス名 (ComputerName)、OS バージョン、アプリバージョン、アクティベート日時、最終アクセス日時。
  • 不正利用防止・運用上のログ: ライセンス検証 API および購入関連 API へのリクエストについて、リクエスト元 IP アドレス、User-Agent、レート制限のために用いるメールアドレス・IP アドレス、検証/購入の成功・失敗の結果、拒否事由 (例: デバイス上限超過、無効なライセンスキー) を記録します。
  • インフラ提供者のアクセスログ: 本サービスは Cloudflare 上で提供しており、Cloudflare が提供する標準的なアクセスログ (IP アドレス、リクエストパス、ステータスコード等) が一定期間記録されます。
  • サポート時の情報: 利用者がサポートに連絡した際に提供されたメールアドレス、お問い合わせ内容、添付された情報。

2. 収集しない情報

  • 本ソフトウェアで操作したファイル名・ファイル内容・コマンド履歴・ターミナル出力
  • 位置情報
  • クラッシュレポート (v1.0 時点では非対応。将来 opt-in 形式での導入を検討する場合があります)

3. 利用目的

収集した情報は、以下の目的でのみ利用します。

  • ライセンスの発行・検証・管理
  • 不正利用 (ライセンスキーの第三者共有等) の防止
  • サポート対応
  • サービス終了時のユニバーサルトークン配布

4. 第三者提供

収集した情報は、以下の場合を除き第三者に提供しません。

  • 利用者の同意がある場合
  • 法令に基づく場合
  • 本サービス運用上必要な業務委託先 (決済: Stripe、メール送信: Resend、インフラ: Cloudflare、配布物および自動アップデート: GitHub、お問い合わせフォーム: HyperForm) への提供

5. 利用する第三者サービス

  • Stripe: 決済処理。プライバシーポリシー
  • Resend: ライセンスキー送付メールの配信。プライバシーポリシー
  • Cloudflare: Web サイトおよび API のホスティング。プライバシーポリシー
  • GitHub (GitHub, Inc.): 本ソフトウェアの配布物 (DMG ファイル) および自動アップデート用フィード (appcast.xml) のホスティング。プライバシーポリシー
  • HyperForm: お問い合わせフォームの送信処理および受付確認メールの配信。サービス概要

6. 自動アップデート (Sparkle) の通信

本ソフトウェアは Sparkle フレームワークを用いた自動アップデート機能を備えており、利用者がアップデート確認操作を行ったとき、および定期的なバックグラウンドチェック時に、GitHub Releases (github.com/nyshk97/polepole-releases) に対してアプリバージョン情報を含む HTTP リクエストを送信します。リクエスト元 IP アドレス、User-Agent 等は GitHub 側のアクセスログに一定期間記録されますが、当方はこれらの情報を取得・保管しません。

7. 保管期間

  • ライセンス情報は、利用者がライセンスを保有する限り保管します。
  • 購入記録は、会計法令その他の関連法令に従い、原則として 7 年間保管します。
  • ライセンス検証・購入関連 API のアクセスログ (拒否ログを含む) は原則として 90 日間保管し、その後は削除または個人を識別できない形に加工します。
  • サポート対応に関する情報は対応完了から原則 1 年間保管します。

8. 安全管理措置

当方は、収集した個人情報の漏えい、滅失または毀損を防止するため、合理的な範囲で以下の安全管理措置を講じます。

  • 個人情報を保管するデータベースおよび管理画面へのアクセス権限を当方の運営者に限定し、認証情報を適切に管理します。
  • 本サービスと利用者の間の通信は TLS で暗号化します。
  • 業務委託先 (Stripe、Resend、Cloudflare) は、いずれも個人情報の保護に関する適切な体制を備えた事業者を選定します。

9. 利用者の権利および請求手続

利用者は、自己の保有個人データについて、開示、内容の訂正・追加・削除、利用停止、第三者提供の停止を、お問い合わせフォームより請求できます。請求にあたっては、ご本人確認のため、ライセンス購入時に登録されたメールアドレスのご記入、またはライセンスキー等の提示をお願いする場合があります。請求にかかる手数料は無料です。請求があった場合、遅滞なく対応し、ご記入のメールアドレス宛に結果を回答します。ライセンス情報の削除は本ソフトウェアの利用停止を伴います。

10. 個人情報取扱事業者

本サービスの個人情報取扱事業者は本ソフトウェアの提供者です。氏名および住所は、特定商取引法に基づく表記に従い、利用者からのご請求があった場合に遅滞なく電子メールにより開示します。

11. 変更

本プライバシーポリシーは予告なく変更される場合があります。変更後は本ページに掲載した時点から効力を生じます。

12. お問い合わせ

本プライバシーポリシーに関するお問い合わせは お問い合わせフォームよりお願いします。
